# 📜 Свод Мужских Правил

Приложение для создания и голосования за универсальные мужские правила. Работает через веб-интерфейс и Telegram бота.

## 🎯 Функционал

**Основное:**
- ✍️ Создание новых правил с названием и описанием
- 👍👎 Голосование за/против правил
- 📊 Рейтинговая система
- 🏆 Топ-10 самых популярных правил
- 🌐 Адаптивный веб-интерфейс
- 🤖 Telegram бот с полным функционалом

**Дополнительно:**
- 🔍 Поиск по правилам в реальном времени
- 📄 Пагинация для больших списков
- 🛡️ Rate limiting для защиты API
- 📈 Статистика и аналитика
- 🐳 Docker поддержка
- 📝 Логирование всех запросов

## 🚀 Быстрый старт

### Требования

- Node.js (версия 16 или выше)
- npm или yarn

### Установка

1. Клонируйте репозиторий:
```bash
git clone <ваш-репозиторий>
cd prikol
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Настройте переменные окружения в `.env`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
PORT=3000
DATABASE_URL="file:./dev.db"
```

### Получение токена Telegram бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и задайте имя бота
4. Скопируйте полученный токен в `.env` файл

### Инициализация базы данных

```bash
npm run prisma:generate
npm run prisma:migrate
```

### Запуск приложения

#### Запуск веб-сервера:
```bash
npm start
```
Веб-интерфейс будет доступен по адресу: http://localhost:3000

#### Запуск Telegram бота:
```bash
npm run bot
```

#### Запуск в режиме разработки (с автоперезагрузкой):
```bash
npm run dev
```

### 🐳 Запуск с Docker

Docker позволяет запустить приложение в изолированной среде без установки зависимостей.

#### Быстрый старт с Docker Compose:

```bash
# Создайте .env файл с токеном бота
echo "TELEGRAM_BOT_TOKEN=ваш_токен" > .env

# Запустите все сервисы
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down
```

#### Сборка отдельного контейнера:

```bash
docker build -t rules-app .
docker run -p 3000:3000 --env-file .env rules-app
```

## 🗄️ База данных

Используется SQLite с Prisma ORM.

### Модели:

- **User** - пользователи (из Telegram или веб)
- **Rule** - правила
- **Vote** - голоса (один пользователь = один голос за правило)

### Схема голосования:

- +1 = согласен с правилом
- -1 = не согласен с правилом
- Рейтинг = сумма всех голосов

## 🔧 API Endpoints

### GET `/api/rules`
Получить все правила с рейтингом

**Параметры (опциональные):**
- `page` - номер страницы (по умолчанию 1)
- `limit` - количество на странице (по умолчанию 50, макс 100)
- `search` - поиск по названию/описанию
- `sortBy` - сортировка: `rating` или `date`

**Пример:**
```
GET /api/rules?page=1&limit=20&search=дружба&sortBy=rating
```

### GET `/api/rules/:id`
Получить конкретное правило

### POST `/api/rules`
Создать новое правило (лимит: 10 в минуту)

```json
{
  "userId": "123",
  "userName": "Иван",
  "title": "Название правила",
  "description": "Описание"
}
```

### POST `/api/rules/:id/vote`
Проголосовать за правило (лимит: 50 в минуту)

```json
{
  "userId": "123",
  "userName": "Иван",
  "value": 1
}
```

### GET `/api/rules/top/:limit`
Получить топ правил

### GET `/api/stats`
Получить статистику приложения

**Ответ:**
```json
{
  "totalRules": 42,
  "totalUsers": 15,
  "totalVotes": 120,
  "positiveVotes": 85,
  "negativeVotes": 35,
  "topRule": {
    "id": 5,
    "title": "Название лучшего правила",
    "rating": 23
  },
  "avgVotesPerRule": "2.86"
}
```

### GET `/api/health`
Health check endpoint

## 📊 Система рейтинга

- Каждый пользователь может проголосовать за правило один раз
- Голос можно изменить (с "за" на "против" и наоборот)
- Правила с самым высоким рейтингом считаются универсальными
- Рейтинг отображается с эмодзи:
  - 🔥 - положительный рейтинг
  - ❄️ - отрицательный рейтинг
  - ⚖️ - нейтральный (0)

## 🎨 Особенности UI

## 🔐 Безопасность

- Один пользователь = один голос за правило
- Уникальный ID пользователя хранится в localStorage (веб) или Telegram ID (бот)
- Возможность изменить свой голос

## 🚀 Развертывание

### На сервере

1. Установите Node.js на сервере
2. Клонируйте репозиторий
3. Установите зависимости: `npm install`
4. Настройте `.env` файл
5. Инициализируйте БД: `npm run prisma:migrate`
6. Используйте PM2 для запуска:
```bash
npm install -g pm2
pm2 start src/server.js --name "rules-server"
pm2 start src/bot.js --name "rules-bot"
pm2 save
pm2 startup
```

### Docker (опционально)

Можно создать Dockerfile для контейнеризации приложения.
