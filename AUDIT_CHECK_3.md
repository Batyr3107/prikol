### 🟡 Средняя #2: Отсутствие валидации limit параметра
**Серьезность:** 🟡 MEDIUM
**Файл:** `src/server.js:112`

**Проблема:**
```javascript
const limit = parseInt(req.params.limit) || 10;
```

Может быть:
- Отрицательным числом: `/api/rules/top/-100`
- Огромным числом: `/api/rules/top/999999`
- Вызвать DoS загрузкой всей БД

**Решение:** ✅ ИСПРАВЛЕНО
```javascript
const limit = Math.min(100, Math.max(1, parseInt(req.params.limit) || 10));
```

Теперь limit в диапазоне 1-100.

### 🟡 Средняя #3: Отсутствие валидации title в боте
**Серьезность:** 🟡 MEDIUM
**Файл:** `src/bot.js:179`

**Проблема:**
Title сохраняется в state БЕЗ валидации:
```javascript
state.title = text; // Может быть 10000+ символов!
```

Валидация происходит только на следующем шаге.

**Последствия:**
- Пользователь может отправить 10000 символов как title
- Память userState будет содержать огромные строки
- Только потом выдаст ошибку

**Решение:** ✅ ИСПРАВЛЕНО
Добавлена ранняя валидация:
```javascript
if (text.length > 200) {
  bot.sendMessage(chatId, '❌ Название слишком длинное...');
  delete userState[userId];
  return;
}
state.title = text;
```

### 🟡 Средняя #4: Отсутствие проверки пользователя в боте
**Серьезность:** 🟡 MEDIUM
**Файл:** `src/bot.js:200-204`

**Проблема:**
```javascript
const user = await prisma.user.findUnique({
  where: { telegramId: userId.toString() }
});

// Создаем правило
const rule = await prisma.rule.create({
  data: {
    authorId: user.id  // ❌ user может быть null!

});
```

Если пользователь не выполнял /start, user === null, будет ошибка.

**Решение:** ✅ ИСПРАВЛЕНО

```javascript
if (!user) {

  delete userState[userId];
  return;
}
```

### 🟡 Средняя #5: Undefined key в rate limiter
**Серьезность:** 🟡 MEDIUM
**Файл:** `src/middleware/rateLimiter.js:31`

**Проблема:**
```javascript
const key = req.ip || req.connection.remoteAddress;
```

Если оба undefined (теоретически возможно), то key = undefined.
Все запросы будут использовать один ключ в Map.

**Решение:** ✅ ИСПРАВЛЕНО
```javascript
const key = req.ip || req.connection.remoteAddress || 'unknown';
```
