# 🚀 Быстрый старт

## Шаг 1: Установка зависимостей

```bash
npm install
```

## Шаг 2: Получение токена Telegram бота

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. Скопируйте полученный токен

## Шаг 3: Настройка окружения

Создайте файл `.env`:

```bash
TELEGRAM_BOT_TOKEN=ваш_токен_здесь
PORT=3000
DATABASE_URL="file:./dev.db"
```

## Шаг 4: Инициализация базы данных

```bash
npm run prisma:generate
npm run prisma:migrate
```

## Шаг 5: Запуск приложения

### Вариант 1: Запустить всё сразу
```bash
npm run both
```

### Вариант 2: Запустить отдельно

Терминал 1 (Веб-сервер):
```bash
npm start
```

Терминал 2 (Telegram бот):
```bash
npm run bot
```

## Готово! 🎉

- **Веб-интерфейс**: http://localhost:3000
- **Telegram бот**: Найдите вашего бота в Telegram и отправьте `/start`

## Автоматическая настройка

Можно использовать автоматический скрипт настройки:

```bash
npm run setup
```

Этот скрипт:
- Создаст `.env` файл
- Установит зависимости
- Инициализирует базу данных
- Всё настроит автоматически

## Дополнительные команды

```bash
npm run dev          # Запуск веб-сервера в режиме разработки
npm run bot:dev      # Запуск бота в режиме разработки
npm run prisma:studio # Открыть Prisma Studio для просмотра БД
```

## Возможные проблемы

### Ошибка "TELEGRAM_BOT_TOKEN не установлен"
- Проверьте что файл `.env` создан
- Проверьте что токен скопирован правильно

### База данных не создается
- Убедитесь что установлен Prisma: `npm install`
- Попробуйте вручную: `npx prisma generate && npx prisma migrate dev`

### Порт уже занят
- Измените порт в `.env`: `PORT=3001`
